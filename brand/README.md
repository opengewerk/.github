# OpenGewerk: Logo-Dateien

Diese Dateien sind die einzige Quelle für das OpenGewerk-Branding. Andere Repos binden sie per Raw-URL ein.

Bildmarke: offener Ring aus sechs Segmenten (Gewerke/Module), die Lücke oben rechts steht für „Open“, das kupferfarbene Segment für das Kernmodul Elektro/PV.
Alle SVGs enthalten die Wortmarke als Pfade (Schrift Barlow, OFL-lizenziert), keine Schriftinstallation nötig.

## Farben
- Schiefer `#1B2430` (Primär, Text)
- Kupfer `#C8671F` (Akzent)
- Elfenbein `#F4F1EA` (heller Hintergrund / Marke auf dunklem Grund)

## Schutzraum
Mindestabstand um die Marke: die Strichstärke des Rings (15 % der Ringbreite). Mindestgröße Bildmarke 16 px, Wort-Bild-Marke 120 px Breite.
